## 一、项目上下文提示词（每次新会话都先粘这段）

````
# 项目：股票记账本（stock-ledger）

## 一句话
纯前端、无后端的个人股票记账 PWA。支持持仓、交易记录、盈亏分析、报表导出、
多券商资金账户、GitHub 私有仓库多端同步。

## 技术栈
Vue 3（<script setup>）+ Vite 5 + Pinia + Element Plus + ECharts
+ sql.js（SQLite WASM，数据存 IndexedDB）+ dayjs + xlsx/jspdf + vite-plugin-pwa

## 目录结构
src/
  main.js              入口（含安卓返回键拦截逻辑）
  App.vue              根组件：数据初始化、PWA 更新提示、离线横幅、底部 tabbar
  constants.js         默认券商等常量
  router/index.js      hash 模式路由
  stores/portfolio.js  持仓与交易数据、行情刷新、指标汇总
  stores/settings.js   设置、标签、汇率、GitHub 同步与备份
  services/calc.js     核心计算：成本、已实现盈亏、净值序列、回撤、月度/年度统计
  services/quotes.js   行情与汇率抓取（腾讯行情 / Yahoo Finance）
  services/github.js   GitHub 私有仓库同步与备份
  services/export.js   Excel / PDF 导出
  db/index.js          sql.js 初始化与 IndexedDB 持久化
  utils/format.js      金额/百分比/涨跌配色/标签解析
  views/               Overview 总览、Assets 资产、Analysis 分析、Trades 交易、
                       Settings 设置、StockDetail 个股详情、Privacy 隐私政策
  components/          TradeForm、CashForm、InitPositionForm、PositionCard、PullRefresh
  styles/main.css      全局样式（.card / .muted / .num / .row.between / .up / .down）

## 运行环境（重要，本机特有问题）
- 本机没有安装全局 Node，PATH 里没有 node / npm，直接敲 node 会报错。
- 可用 Node：C:\Users\surface\.workbuddy\binaries\node\versions\22.22.2\node.exe
- 启动开发服务器（后台运行）：
  Start-Process -FilePath "上述 node 路径" -ArgumentList ".\node_modules\vite\bin\vite.js","--host","--port","5173" -WorkingDirectory 项目根目录 -WindowStyle Hidden
- 预览地址：http://localhost:5173
- 构建需要 30~60 秒，请后台执行并轮询日志，不要在 10 秒内就判定失败

## 部署
- 线上地址：https://soldier009.github.io/stock-ledger/
- 推送到 main 后，GitHub Actions（.github/workflows/deploy.yml）自动构建发布到
  gh-pages 分支，约 1 分钟生效
- vite base 为 './'（相对路径），产物可用于域名根目录或子目录
- 已不再维护 CloudBase 部署

## 开发约定
1. 版本号唯一来源是 package.json 的 version，界面通过 __APP_VERSION__ 显示。
   每次提交都要升一个小版本号，并在提交信息末尾加 `; v1.1.x`。
2. 本机 git 未配置 user.name / email，提交前须用环境变量指定：
   $env:GIT_AUTHOR_NAME="soldier009"
   $env:GIT_AUTHOR_EMAIL="soldier009@users.noreply.github.com"
   $env:GIT_COMMITTER_NAME="soldier009"
   $env:GIT_COMMITTER_EMAIL="soldier009@users.noreply.github.com"
3. 推送必须用 SSH（github.com:443 在本机会被拦截）：
   git push git@github.com:soldier009/stock-ledger.git main
4. 代码注释与交流一律用中文。
5. 移动端优先：按手机宽度（约 390px）设计，字号偏小、布局紧凑。
6. 不要提交 dist/ 和 generated-icons/（已在 .gitignore）。

## 已知坑（改动前务必注意）
- 路由是 hash 模式（createWebHashHistory），URL 形如 /#/assets
- 数据全部在浏览器 IndexedDB，卸载应用或清缓存 = 数据永久丢失，
  涉及数据安全的功能要提醒用户开启 GitHub 同步
- 有 Service Worker 缓存，用户手机上不会立刻看到更新，App.vue 已做新版本提示
- 行情来自第三方免费公开接口，可能超时或失败，代码要容忍失败并提示用户
- PWA 图标在 public/icons（192 / 512 / maskable / apple-touch-icon），
  换图标必须导出全套尺寸；manifest 与 PWA 配置在 vite.config.js
- 安卓返回键拦截逻辑在 main.js，只在全屏 PWA 模式生效，不要改成全局生效

## 协作偏好
- 我是非研发人员，请用大白话解释，不要堆技术术语
- 改动前先读清楚现有实现，小步修改，不要大范围重写
- 改完必须本地构建验证，并在 http://localhost:5173 预览确认
- 完成后告诉我改了哪些文件、怎么验证，等我明确说"推送"再提交推送
- 涉及引入新依赖、改变数据结构等重大决策，先问我
````
